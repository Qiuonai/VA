# Virtua Agency Landing

A modern, sleek landing page for a Virtual Assistant Agency built with Next.js and Tailwind CSS.

## Getting Started

1. **Upload to GitHub:**
   - Create a new repository on GitHub.
   - Initialize git and push these files.

2. **Deploy to Vercel:**
   - Go to [Vercel](https://vercel.com).
   - Import your GitHub repository.
   - Vercel will automatically detect Next.js and deploy your site for free.

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
